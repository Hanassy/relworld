משחק סאטירה איזומטרי על הדרך למנכ"לות: 110 קומות של היי-טק, צ'אפחות האצה,
חומרה מכל תקופה, מנהלים מקבילים ודלתות שאף אחד לא יודע מי נעל.
הכל רץ בדפדפן, בלי שרת, בלי build ובלי ספריות חיצוניות.

**להרצה:** פתח את `index.html` בדפדפן. זהו.
(או `python3 -m http.server` בתיקייה, אם בא לך URL.)

## פריסה ותצוגה

המשחק ממלא את המסך, לא קופסה בגודל קבוע: ה-canvas תופס את כל מה שנשאר אחרי
הסרגל העליון, והמנוע **מתאים את שדה הראייה הלוגי לצורת החלון** — אין מתיחה ואין
פסים שחורים, לא במסך רחב ולא בטלפון. במסך 1920×1080 המשחק תופס 96% מהחלון
(לפני כן: 29%). יש כפתור מסך מלא (`F`), וגם F11 של הדפדפן עובד עכשיו כמו שצריך.

במסך רחב טקסט התדריך עובר לעמודה בצד, כך שהבניין והקומה מקבלים את כל הגובה.
במכשיר בלי מסך מגע הד-פד מוסתר אוטומטית (יש מקלדת), ובטלפון אופקי כל הממשק
מתכווץ כדי לפנות פיקסלים לקומה.

## התדריך הקולנועי

לפני כל קומה הבניין כולו נפרש על המסך למשך כמה שניות — גורד שחקים עם חלונות
מוארים, שכנים וכביש, והקומה הפעילה מהבהבת בתכלת. אחר כך המצלמה נכנסת פנימה,
הקירות מתמוססים, והקומה כולה נפרשת בזום-אאוט אחד — ואז המצלמה עוברת בין המשתתפים: צוות העובדים הגדול, המנהל
המקביל — **ולבסוף נעצרת על דלת היעד ונשארת עליה**, כדי שיהיה ברור לאן רצים. במקביל המערכת **מקריאה את המשימה בקול ומדגישה כל מילה** תוך
כדי קריאה, והמצלמה מתקדמת בין הזוויות לפי התקדמות ההקראה.

הסבר על החץ המהבהב נאמר רק בקומות הראשונות — אחר כך ההקראה רק מציינת את שם
היעד, בלי לחזור על אותו משפט כל פעם.

ההקראה משתמשת ב-`speechSynthesis` של הדפדפן עם קול עברי. אם אין קול עברי
מותקן, המשחק **לא** מעוות את העברית דרך קול אנגלי — הוא עובר להדגשת מילים
שקטה בקצב קריאה. אפשר לכבות הכל ב-🗣️, ולדלג על התדריך בכל רגע.

**המשחק נפתח בציטוט, על מסך משלו.** ״התחל קריירה חדשה״ לא קופץ ישר לתדריך: קודם
עולה מסך מלא — אותו מסך שסוגר קומה, רק שכתוב בו **״התחלת קריירה חדשה״** ובכפתור
**״היכנס לבניין״** — ובו ציטוט אחד, ״מחשב על כל שולחן ובכל בית״, שמוקרא במלואו.
המסך ממתין לך; הוא נעלם רק כשאתה לוחץ. בציטוט הפותח ובזה שסוגר כל קומה מוקראת גם
שורת הייחוס: מי אמר, ובאיזו שנה.

## איך מנצחים קומה

לכל קומה שלוש משימות, ושלושה סוגי קומות:

- **קומת מעלית 🔼** — לאסוף את החומרה של התקופה, לשדרג את כל העמדות, לחלק צ'אפחות לכולם, לרדת במעלית.
- **קומת ישיבה 🗓️** — לאסוף מכסת תקציב 🪙, לחלק צ'אפחות, להגיע לחדר הישיבות.
- **קומת HR 👩‍⚖️** — לסיים עם העובדים, ורק *אז* לתת צ'אפחה לבוסניק 👺 — ואז מירוץ ל-HR לפניו.

### החומרה משתנה לפי התקופה

מה שאתה תוקע לעובד בעמדה הוא מה שהיה חדש **באותה שנה**, לא GPU בכל מקום. לכל קומה
יש `era` — השנה שבה המשימה מתרחשת — והיא בוחרת רכיב מתוך סולם כרונולוגי אחד
(`REL_TECH` ב-`src/levels.js`):

| שנה | מה מחלקים | | שנה | מה מחלקים |
|---|---|---|---|---|
| עד 1970 | 🗂️ כרטיס ניקוב | | 2001–2003 | 💽 דיסק-און-קי |
| 1971–1976 | 💾 תקליטון 8 אינץ' | | 2004–2006 | 🖥️ מסך LCD שטוח |
| 1977–1982 | 💾 תקליטון 5.25 | | 2007–2009 | ⚡ כונן SSD |
| 1983–1984 | 💾 תקליטון 3.5 | | 2010–2012 | ☁️ שרת ענן |
| 1985–1989 | 🛢️ דיסק קשיח 20 מגה | | 2013–2016 | 🖥️ מסך 4K |
| 1990–1995 | ☎️ מודם חיוג | | 2017–2021 | 🟩 כרטיס GPU |
| 1996–1998 | 💿 כונן CD-ROM | | 2022+ | 🟩 מאיץ H100 |
| 1999–2000 | 📀 צורב DVD | | | |

GPU מופיע רק מ-2017 ואילך, ו-**שום קומה שלפני שנת 2000 לא מחלקת GPU** — שלוש
המשימות המקוריות (1–3) מתרחשות ב-1981–82, בקומה שבה המחשב עוד חדש.

`era` נגזר משנת הציטוט של הקומה, ונכתב במפורש רק כשהציטוט הוא מבט לאחור (קומה 14
על ויסטה) או בשלוש המשימות המקוריות, שמתרחשות היום. הרכיב משנה את מה שנאסף על
הרצפה, את הכיתוב והצבע של הכרטיס המותקן על השולחן, את הסמל והמונה ב-HUD ואת
ניסוח המשימה עצמה. הבדיקות מוודאות שאף קומה לא מחלקת חומרה שלא הייתה קיימת בשנתה,
ושאין דרגה בסולם שאף קומה לא נוחתת עליה.

### רואים עברית תקינה, שומעים עברית פונטית

לכל משימה יש **שתי גרסאות**. `text` היא עברית רגילה ותקינה — זה מה שהשחקן קורא.
`say` היא אותן מילים בדיוק עם ניקוד פונטי ועם שגיאות כתיב מכוונות — וזה מה שנשלח
למנוע ההקראה, ולעולם לא מוצג.

השתיים נוצרות **מילה מול מילה** זו מזו, אז למילה מספר N באחת מתאימה מילה מספר N
בשנייה. ככה ההדגשה מאירה את **האיות הנכון** בזמן שהקול מבטא את **הצורה
הפונטית**: על המסך `כל`, באוזן `כּוֹל`; על המסך `צ'אפחות`, באוזן `צַ'פּחוֹת`.

הניקוד עצמו **אינו תקני בכוונה**. הוא נכתב בשביל מנוע ההקראה, לפי כלל אחד:
*כותבים את התנועה שבאמת שומעים.*

- **אין שווא.** המנוע בולע אותו. שווא במילית יחס (ל, ב, כ, ו) הופך לצירה —
  `לֵשָׁם`, לא `לַשָׁם`; שווא באות הפותחת של המילה עצמה הופך לפתח — `מַנכָּ"ל`,
  לא `מֵנַכָּ"ל`.
- **אין קמץ בהברה סגורה**, שבה המנוע עלול לקרוא אותו `/o/`. שם בא פתח:
  `צַנחָה`, לא `צָנחָה`. זאת אותה מלכודת שבגללה `כל` נכתב `כּוֹל`.
- **אות שנשמעת נכתבת, ואות שלא — יורדת:** `כּוֹל` עם ו', `צַ'פּחוֹת` בלי א'.

המילון יושב ב-[`tools/niqqud.json`](tools/niqqud.json) — ערך אחד לכל מילה,
1164 מילים. מילה שנשמעת רע מתוקנת **פעם אחת**, וכל המשימות שמשתמשות בה
מתעדכנות:

```sh
node tools/vocalize.js          # מייצר את say/saySub מתוך text/sub
node tools/vocalize.js --check  # נכשל אם הם לא מעודכנים או לא מיושרים
```

הבדיקות אוכפות את כל זה: אין שווא, אין `כָּל` בקמץ, אין א' נשמעת, **מה שמוצג
לא מנוקד כלל**, מה שמוקרא כן, והשניים מיושרים מילה-מול-מילה. יש גם בדיקה
שמריצה את ההקראה ומוודאת שהמילה שמוארת על המסך היא האיות התקין של המילה שהקול
אומר באותו רגע.

זה חל על **כל מה שמוקרא**: 110 משימות הקריירה, משימות החדשות, שורות הקריין
והכתב במהדורה, ההכרזה של ה-twist, משפט הסיכום, ו-111 הציטוטים — כולל שם המצטט
והשנה.

**משימות הן נוקשות וציטוטים רכים**, וזה בכוונה. את המשימות אנחנו כותבים, אז
מילה שהמילון לא מכיר היא טעות והבנייה נופלת. ציטוט הוא משפט של מישהו אחר,
מצוטט כלשונו, מלא בשמות משפחה ובמילים שמופיעות פעם אחת בכל המשחק — ולהפיל על
זה את ה-CI פירושו שכל ציטוט חדש חוסם עד שמישהו ינקד שם משפחה. אז ציטוט לוקח
את מה שהמילון מכיר, משאיר את השאר כמו שנכתב (מה שהמנוע קיבל ממילא לפני שכל זה
היה קיים, אז זה אף פעם לא גרוע יותר), וההרצה מדפיסה את האחוז. כרגע 60%.

### קומות של אנשים

עשר קומות עוסקות ביחסים בין עובדים ובקידום, ולא בחומרה: טים קוק מפרסם את המאמר שלו
(2014), עשרים אלף עובדי גוגל יוצאים מהבניין (2018), מנכ"ל אינטל נופל על סעיף
אי-ההתרועעות שהוא עצמו אכף (2018), אלן פאו תובעת את קליינר פרקינס (2015), מריסה
מאייר לוקחת שבועיים חופשת לידה (2015), ואידי וינדזור — מתכנתת IBM לשעבר — מגיעה
לבית המשפט העליון (2013). שתי קומות הן קומות כלבים: סעיף הכלבים בקוד ההתנהגות של
גוגל, וספוט הרובוטי. קומה 90 היא הקרב על הסמנכ"לות, וקומה 110 — הגראנד
פינאלה — היא הקרב על המנכ"לות עצמה.

בקומת **התחפושת** אתה מתחפש כדי לעקוף את צ'אד בדרך לגרומינג, והדמות על המסך
משתנה בהתאם: לקומה יש שדה `avatar` שמחליף את הסמל של השחקן, והבדיקות מוודאות
שהוא מופיע שם ורק שם.

**יעד הקומה זז.** הדלת לא נמצאת תמיד באותה פינה — בכל קומה היא מוגרלת (דטרמיניסטית
לפי מספר הקומה) למקום מרוחק מנקודת ההתחלה. כדי שלא תלכו לאיבוד, שם היעד —
`HR`, `GROOMING`, `מעלית`, `VC` וכו' — מופיע **לאורך כל המשחק** על שלט מהבהב:
מעל הדלת עצמה כשהיא בשדה הראייה, ועל חץ מהבהב בקצה המסך שמצביע לכיוונה כשהיא לא.
גם במיני-מפה היעד מהבהב.

🔑 מפתח פותח דלת כתומה. 🗝️ מאסטר פותח דלתות אדומות — וגם **נועל** אותן מחדש,
מה שמאוד שימושי כשמנהל מקביל רודף אחריך.

המנהל המקביל לא מפטר אותך במכה אחת: כל תפיסה היא **אזהרה** (⚠️), ושלוש אזהרות
מסיימות את הקריירה. אפשר להשתיק אותו בצ'אפחה כדי להמם אותו לכמה שניות.

ניקוד: פעולות רצופות בונות **קומבו** (עד x5), וסיום קומה משלם בונוס זמן ובונוס
על קומה בלי אזהרות. ההתקדמות, השיא האישי וטבלת המייסדים נשמרים מקומית בדפדפן.

## חדשות מתפרצות

משימה אחת בשבוע, בנויה על הסיפור הגדול של אותו שבוע בעולם הטכנולוגיה. היא
נבחרת מפאנל בתפריט לפי כותרת, תאריך ותיאור, ומוצגת **בתוך טלוויזיה**: פתיח
"חדשות מתפרצות", אולפן עם קריין מאחורי שולחן, קאט לכתב בשטח, שליש תחתון,
כתוביות שרצות עם ההקראה, שורת חדשות רצה בתחתית וסיומת — ואז התדריך הרגיל.

**לכל משימת חדשות יש `twist`** — דבר אחד שהיא עושה והמגדל לא יכול, אחרת זאת
קומה 111 עם מסגרת אדומה. ההגעה ליעד הראשון נותנת לך את הדבר, הופכת אותך אליו,
ומעבירה את היעד לצד השני של הקומה. ב-Roadster: מגיעים למכונית, ומשם רואים רק
מכונית — וצריך להביא אותה למסלול. בסוף נקרא `outro`, משפט הסיכום של המשימה,
לפני הציטוט האמיתי. `tools/news-add.js` מסרב לטיוטה בלי שניהם, ויש בדיקה
שמשחקת את ה-twist עד הסוף.

**המשימות האלה אינן קומות.** המגדל הוא 110 קומות ונשאר 110: משימת חדשות אינה
מזיזה את מונה הקריירה, לא פותחת קומה ולא משנה את המספור, כדי שקובץ השמירה
יישאר תקף ולא משנה כמה שבועות עברו. בקוד זה `FLOORS` מול `LEVELS.length`, ויש
בדיקה שנופלת אם השניים מתבלבלים.

**התהליך השבועי:** משימה מתוזמנת מעירה את Claude בכל יום שני, הוא מחפש ברשת מה
קרה, מאמת ביותר ממקור אחד, בונה את המשימה ואת ה-twist, מריץ את הבדיקות ודוחף
ל-`staging` — **אף פעם לא ל-main**. המיזוג הוא החלטה של בן אדם, וזו הנקודה: אלה
בדיחות על אנשים בשמם, שנכתבות באותו שבוע שבו הדבר קרה ומתפרסמות לכתובת ציבורית.
הבריף המלא — הטון, ה-twist, ומה שלא נכנס — נמצא ב-[`.github/WEEKLY-NEWS.md`](.github/WEEKLY-NEWS.md).

## בדיקת נעילות (תורת גרפים)

מפתח שנעול מאחורי הדלת שהוא עצמו פותח = שלב בלתי אפשרי. כדי שזה לא יקרה,
`reachableWithKeys()` מריץ חיפוש על **גרף המצבים של הדלתות**:

- **צומת** = קבוצת הדלתות הפתוחות כרגע (ביטמסק).
- **קשת** = פתיחת דלת *נוספת*, חוקית רק אם (א) אפשר להגיע אליה מהאזור הנוכחי,
  ו-(ב) אפשר לשלם עליה — מפתח שכבר **נאסף בפועל** (מאסטר-קי לא מתכלה).
- בכל צומת עושים BFS על הרצפה כשדלתות סגורות נחשבות קיר, וסופרים את המפתחות
  שבאזור שהתקבל.
- התוצאה: האזור **הגדול ביותר שבאמת ניתן להגיע אליו**, ורשימת הדלתות ש"נתקעו" —
  דלתות שאפשר לגעת בהן אבל אי אפשר לפתוח. `stuck.length > 0` = בדיוק הבאג.

לכל קומה יש קומץ דלתות, אז 2^n זניח (יש תקרה של 12 דלתות ליתר ביטחון).

`repairLocks()` מתקן קומות סוררות: כל פריט שלא ניתן להגיע אליו מועבר לתוך האזור
הנגיש, וכל דלת "תקועה" מקבלת מפתח בתוך האזור — ואז הבדיקה רצה שוב, כי כל תיקון
יכול לפתוח שטח חדש. **91 מתוך 100 הקומות היו שבורות** (221 תיקונים); אחרי
התיקון אפסקומות עם דלת חסומה.

חשוב: הבדיקה הקודמת לא יכלה לתפוס את זה בכלל — `reachableFrom()` עובר דרך דלתות
כאילו תמיד יש מפתח. יש גם **בקרת שלילה** בבדיקות: קומה סינתטית שבה המפתח היחיד
נמצא אחרי הדלת — והאלגוריתם חייב לדווח עליה ככשל.

## מה שופר מול הגרסה המקורית

**באגים אמיתיים שתוקנו**

- השחקן נולד **בתוך קיר** (`map[17][17]` היה קיר), והיריב נולד **בתוך שולחן**.
  נקודות הלידה נבדקות עכשיו מול המפה שנוצרה.
- כל הפסד עשה `location.reload()` — כלומר איבוד הניקוד וחזרה לטעינת דף.
  עכשיו יש מסכי סיום אמיתיים עם "נסה שוב" מאותה קומה.
- `alert()` / `prompt()` חוסמים הכל (ובנייד זה אסון) — הוחלפו בשכבות בתוך המשחק.
- לחיצה קצרה על מקש לא הזיזה את השחקן: ה-`keyup` הקדים את הפריים הבא.
- בניין הרקע צויר בלי היסט המרכז, ולכן לא התיישר עם תוכנית הקומה בזמן המעבר.
- הקומות נוצרו עם `Math.random()` — אותה קומה נראתה אחרת בכל טעינה.
  עכשיו ה-RNG מזורע לפי מספר הקומה.
- `player` נוצר כמשתנה גלובלי משתמע, ו-`localStorage` לא היה עטוף ב-`try/catch`
  (קריסה בגלישה פרטית).
- בנייד, RTL שיקף את הד-פד: הכפתור השמאלי הזיז ימינה.
- הטיימר רץ על `setInterval` והמשיך לרוץ בטאב מוסתר.

**משחקיות**

- כל קומה נבדקת ב-BFS ומתוקנת אוטומטית: אין יותר שולחן, מפתח או חלק חומרה שאי אפשר
  להגיע אליו, ותמיד יש מספיק מפתחות לדלתות.
- תקציב הזמן מחושב לפי העומס האמיתי של הקומה ומתהדק עם הגובה (228 שניות בתחתית,
  143 בפסגה) במקום נוסחה שנתנה לכולן אותו זמן.
- קומת ישיבה דורשת **מכסת** תקציב (60%) במקום 82 מטבעות עד האחרון.
- היריב משתמש ב-BFS אמיתי במקום מהלך חמדני שנתקע בקירות — ובתמורה, תפיסה עולה
  אזהרה ולא פיטורים מיידיים, ואפשר להמם אותו בצ'אפחה.
- מירוץ ה-HR נפתח רק אחרי שאר המשימות, אחרת הצ'אפחה המוקדמת הייתה הפסד ודאי.
- קומבו, בונוס זמן, בונוס ללא אזהרות, שיא אישי וטבלה של 10 מקומות.
- 12 תמות סאטירה במקום 6.
- **קומות 1–3 הן המשימות המקוריות** של המשחק, והן הטוטוריאל: קומה 1 היא זו
  שמסבירה *למה* מחלקים צ'אפחות — כך מאיצים הספק בחברה הזאת — ואחריה הגרומינג
  והמירוץ ל-HR. שלושתן מסתיימות בציטוטים העתיקים במשחק (טיילור 1911, פרקינסון
  1955, עקרון פיטר 1969).
- **96 קומות נוספות** מבוססות על אירועים אמיתיים מתולדות ההיי-טק — מפרסומת
  המקינטוש של 1984, דרך בלוקבאסטר שצוחקת על נטפליקס, ועד עידן ה-AI (ChatGPT,
  סידני, הדחת אלטמן, NVIDIA). **בסיום כל קומה מופיע ציטוט אמיתי שמתאים בדיוק
  לאותה משימה**, עם השם והשנה. ציטוטים מיוחסים/משוחזרים מסומנים ככאלה.
  כל המשימות והציטוטים מרוכזים בקובץ [`LEVELS.md`](LEVELS.md) לקריאה.
- **כל קומה היא מבוך אחר.** המבוך נוצר פרוצדורלית ומזורע לפי מספר הקומה — חדרים,
  מסדרונות, דלתות וקיצורי-דרך משתנים בכל קומה (פריסה שונה לכל קומה, אומת בבדיקה).
  קודם לכן כל 100 הקומות השתמשו באותה פריסה אחת עם 6 שינויים זעירים.
- **המבוך מותאם לנושא המשימה** דרך "סצנה": צורת המבוך, **צבע הקירות** וה"סט"
  נקבעים לפי הנושא — 🎬 אולם קולנוע, ⚖️ בית משפט, 🖥️ מעבדה/שרתים, 💹 בנק/בורסה,
  🏛️ דירקטוריון, 🏢 משרדים.
- **כל חדר מרוהט כמו המקום שהוא מתיימר להיות**, כך שמה שרואים מתאים למשימה:
  אולם הקרנה/בית משפט = **שורות מושבים משני צדי מעבר מרכזי** שעוברים בו ומחלקים
  צ'אפחות, מול **קיר-מסך שחור דינמי** (פס אור נע) עם כיתוב; חדר דירקטוריון =
  שולחן ארוך עם שתי שורות זו מול זו; חדר שרתים = שורות ראקים עם מעברי קירור;
  רצפת מסחר = שורות עמדות מול טיקר; משרד = קוביות 2×2 עם מעברים.
  בכל חדר הטבעת החיצונית נשארת פנויה, כך שלכל מושב יש מעבר לצידו.
- תדריך קולנועי עם הקראה והדגשת מילים, במקום חלון טקסט סטטי.
- דלת היעד מוגרלת בכל קומה (50 מיקומים שונים ב-100 קומות) במקום פינה קבועה,
  ושם היעד מסומן כל המשחק בשלט וחץ מהבהבים.

**גרפיקה**

- **זווית הצילום הורמה כלפי מעלה** (יחס האריח 60×46 במקום 60×35) והקירות

## פרסום, קרדיט והבהרה

### איך זה עולה לאוויר

`.github/workflows/ci.yml` מריץ על כל push את הליטינג, את בדיקת הניקוד ואת 68 הבדיקות בכרומיום, ורק אם `main` ירוק הוא מפרסם ל-GitHub Pages. אין build — זה
HTML סטטי, אז ה"בנייה" היא העתקה.

**צעד ידני אחד, פעם אחת, לפני שה-deploy יצליח:** Settings ← Pages ← Build and
deployment ← Source: **GitHub Actions**. אי אפשר לעקוף את זה מתוך ה-workflow —
ה-`GITHUB_TOKEN` אינו מורשה *ליצור* אתר Pages, רק לפרסם לאחד שכבר קיים.

### גרסאות: למה מבקר חוזר לא נתקע על גרסה ישנה

GitHub Pages מרשה לדפדפן לשמור את `index.html` במטמון, ודף שמור מושך את
הסקריפטים השמורים שלו — כך שאפשר לדחוף גרסה חדשה ומישהו עדיין ישחק בישנה.

שתי שכבות מטפלות בזה:

1. **כתובות הנכסים נושאות את מספר הגרסה.** ב-`index.html` כתוב `src/game.js?v=dev`,
   וה-CI מחליף את `dev` ב-SHA של הקומיט בזמן הפרסום. כתובת שמשתנה עם כל קומיט
   לא יכולה להישלף מהמטמון.
2. **דף ישן מזהה את עצמו.** בטעינה המשחק מבקש את `version.json` עם המטמון
   עקוף, ואם ה-build שם שונה מזה שנטען — הוא טוען את עצמו מחדש דרך כתובת
   שהדפדפן לא ראה. מוגן ב-`sessionStorage` כדי שלא ייכנס ללולאה.

מספר הגרסה מוצג בתחתית מסך ההבהרה, כדי שאפשר לוודא מה חי כרגע.

**שים לב:** זה נוגע ל*קוד* בלבד. ההתקדמות, השיאים וההגדרות יושבים ב-localStorage
וממשיכים לחיות בין גרסאות — זה מכוון. למחיקה: כלי הפיתוח ← Application ←
Local storage, או מצב גלישה פרטית.

### הקרדיט

כל מה שקשור לחברה יושב בקובץ אחד, [`src/brand.js`](src/brand.js) — שם, קישור,
לוגו, UTM והבהרה. אין שום אזכור של החברה בתוך מנוע המשחק.

הקישור, והשיתוף הוא כל העניין. יש בדיקה שנכשלת אם קרדיט מופיע בזמן משחק.

כל קישור נושא `utm_source=relworld` ו-`utm_content` לפי המיקום, כדי שאפשר יהיה
להבדיל בין מי שהגיע מהמשחק למי שהגיע מפוסט עליו.

### אנליטיקס

**כבוי כברירת מחדל ולא שולח כלום לאף אחד.** בדיקות מוודאות גם שלא נטען סקריפט
צד-שלישי, וגם שאף מונה לא יורה — כל עוד `analytics.src` ריק.

להדלקה: ממלאים שדה אחד ב-[`src/brand.js`](src/brand.js).

**Google Analytics 4** — מדביקים את ה-Measurement ID מה-data stream:

```js
analytics: { ga4: 'G-XXXXXXXXXX', cookieless: true, events: true }
```

`cookieless: true` מפעיל Consent Mode עם `analytics_storage: 'denied'` — מודדים
בלי קוקיז, בלי באנר הסכמה, במחיר של אי-זיהוי מבקר חוזר כאותו אדם.

**כל השאר** (Plausible, Umami, GoatCounter, Cloudflare) — URL של סקריפט ומאפייני
`data-`:

```js
analytics: {
  src: 'https://cloud.umami.is/script.js',
  attrs: { 'data-website-id': 'ה-id-שלך' },
  events: true
}
```

`track()` מזהה לבד מי מהספקים נטען. ב-GA4 שמות האירועים נשלחים עם קו תחתון
(`career_start`), כי גוגל דוחה מקף.

**מה נספר** (אין בזה שום מידע אישי):

| אירוע | מה זה עונה |
|---|---|
| `career-start` | כמה באמת התחילו לשחק, ולא רק נחתו בתפריט |
| `floor-cleared` + מספר קומה | **עקומת הנטישה** — עד איפה אנשים מגיעים |
| `career-end` + קומה, ניצחון | כמה פוטרו, כמה הגיעו למנכ"לות |
| `share` | האם מישהו לחץ שתף |
| `credit-click` | כמה עברו לאתר, ומאיזה מסך |

**ב-GA4 יש מלכודת:** פרמטרים של אירועים (כמו מספר הקומה ב-`floor_cleared`)
נאספים אבל **לא מופיעים בדוחות** עד שרושמים אותם כ-Custom dimension:
Admin ← Custom definitions ← Create custom dimension ← Event-scoped ← parameter
`floor`. בלי זה תראה כמה קומות נוקו, אבל לא אילו.

**הערה על הבחירה:** Cloudflare Web Analytics חינמי ובלי הגבלה אבל לא מקבל
אירועים מותאמים. GA4 מקבל, אבל חוסמי פרסומות מסננים אותו — מול קהל מפתחים זה
חיתוך משמעותי במספרים. Umami ו-Plausible עוברים את החוסמים ולא צריכים באנר.

של האנשים הרשומים לידם ומובאים לשם פרשנות ופרודיה, ו**שמות החברות והמוצרים**,
שהם סימני מסחר של בעליהם ומוזכרים לשם פרודיה בלבד — המשחק אינו מסונף לאיש מהם.
